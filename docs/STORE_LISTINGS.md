# Store-Texte

Fertig zum Einfügen in Play Console und App Store Connect. Pro Sprache ein Block.

**Limits.** Play: Name 30, Kurzbeschreibung 80, Beschreibung 4000. App Store: Name 30,
Untertitel 30, Keywords 100 (kommagetrennt, **ohne Leerzeichen** nach dem Komma — jedes
Leerzeichen kostet ein Keyword-Zeichen), Werbetext 170, Beschreibung 4000.

**Keywords nicht wiederholen**, was schon im Namen oder Untertitel steht — Apple indexiert
beides ohnehin. Play indexiert Name, Kurzbeschreibung und Beschreibung.

Zeichenzahlen prüft `npm run check-store-listings` (siehe `scripts/check-store-listings.js`).
